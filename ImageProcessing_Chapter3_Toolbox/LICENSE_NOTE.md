# یادداشت مجوز و تصاویر

تصاویر کتاب Gonzalez & Woods داخل این بسته بازتوزیع نشده‌اند. برای رعایت حقوق نشر، GUI از تصاویر نمونه‌ای که همراه `scikit-image` نصب می‌شوند و تصاویر مصنوعی تولیدشده در لحظه استفاده می‌کند. فایل TeX پیوست کاربر فقط به‌عنوان مرجع آموزشی در پوشه `reference/` کپی شده است.

کد این بسته برای استفاده آموزشی تولید شده است. مجوز کتابخانه‌های وابسته تابع مجوز همان پروژه‌هاست؛ به مخازن رسمی در `GITHUB_REFERENCES.md` مراجعه کنید.
