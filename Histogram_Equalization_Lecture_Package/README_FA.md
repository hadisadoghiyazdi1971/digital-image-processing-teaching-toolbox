# بسته جزوه متعادل‌سازی هیستوگرام - نسخه آفلاین v4 + GUI

این نسخه همان هسته آفلاین موفق v3 را حفظ می‌کند و فقط یک رابط گرافیکی سبک مبتنی بر `Tkinter` استاندارد Python 3.12 روی آن اضافه می‌کند.

## اصل طراحی
هیچ تغییری که وابستگی به PyPI را برگرداند انجام نشده است. بنابراین اجرای اصلی و GUI:

1. فقط Python 3.12 x64 را بررسی می‌کنند.
2. محیط مجازی نمی‌سازند.
3. `pip` را اجرا یا ارتقا نمی‌دهند.
4. هیچ `pip install` ندارند.
5. به `pypi.org` یا `files.pythonhosted.org` وصل نمی‌شوند.
6. به NumPy، Matplotlib یا OpenCV وابسته نیستند.

## اجرای GUI
وارد پوشه `code` شوید و روی فایل زیر دوبار کلیک کنید:

`RUN_GUI.bat`

در GUI می‌توانید تصویر انتخاب کنید، یک عملیات را اجرا کنید، پیش‌نمایش قبل/بعد و معیارهای عددی را ببینید و پوشه خروجی را باز کنید.

## اجرای همه دموها بدون GUI
روی `RUN_ALL.bat` دوبار کلیک کنید.

## تست سلامت GUI
روی `TEST_GUI_CORE.bat` دوبار کلیک کنید. این تست بدون بازشدن پنجره، هسته پردازش را اجرا می‌کند.

## الگوریتم‌های موجود
- Histogram و normalized histogram
- Global Histogram Equalization
- Histogram Matching / Specification
- CLAHE مستقل از OpenCV
- BBHE
- Shannon Entropy
- KL divergence to uniform histogram
- Joint Histogram
- Mutual Information

## ورودی تصویر
بدون ورودی، تصویر مصنوعی آموزشی ساخته می‌شود. در حالت کاملاً بدون وابستگی، PGM و BMP خوانده می‌شوند. PNG/JPEG فقط در صورتی خوانده می‌شوند که Pillow از قبل روی سیستم موجود باشد؛ نصب Pillow بخشی از برنامه نیست.

## خروجی‌ها
خروجی‌ها در `code\outputs` ذخیره می‌شوند و فایل TEX/PDF جزوه نیز در ریشه بسته قرار دارد.
