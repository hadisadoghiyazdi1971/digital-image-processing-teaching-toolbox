# اجرای کدها - نسخه آفلاین + GUI

این نسخه برای حذف کامل مشکل PyPI نوشته شده و GUI نیز هیچ وابستگی جدیدی ایجاد نمی‌کند.

## اجرای رابط گرافیکی
روی `RUN_GUI.bat` دوبار کلیک کنید.

GUI امکانات زیر را دارد:

- انتخاب تصویر ورودی یا استفاده از تصویر مصنوعی آموزشی
- انتخاب تصویر مرجع برای Histogram Matching
- اجرای مستقل Histogram
- اجرای Global Histogram Equalization
- اجرای Histogram Matching
- اجرای CLAHE
- اجرای BBHE
- اجرای بخش Information Theory
- اجرای همه دموها با یک دکمه
- نمایش پیش‌نمایش ورودی و نتیجه
- نمایش Mean، Standard Deviation، Shannon Entropy، KL و AMBE
- نمایش Mutual Information در آزمایش نظریه اطلاعات
- بازکردن مستقیم پوشه خروجی‌ها

GUI با `Tkinter` استاندارد Python 3.12 ساخته شده است و از pip/PyPI استفاده نمی‌کند.

## اجرای خط فرمان
روی `RUN_ALL.bat` دوبار کلیک کنید.

- نیاز: Python 3.12 x64 + Python Launcher (`py.exe`)
- بدون `pip install`
- بدون اتصال اینترنت
- بدون NumPy
- بدون Matplotlib
- بدون OpenCV
- بدون ساخت `.venv`

## تست هسته GUI
روی `TEST_GUI_CORE.bat` دوبار کلیک کنید. این فایل همه توابع اصلی GUI را بدون باز کردن پنجره تست می‌کند.

## ورودی تصویر
اجرای پیش‌فرض هیچ فایل خارجی لازم ندارد و یک تصویر مصنوعی آموزشی می‌سازد.

حالت کاملاً بدون وابستگی فایل‌های `PGM` و `BMP` را می‌خواند. اگر Pillow از قبل روی سیستم نصب باشد، PNG/JPEG نیز قابل خواندن است؛ ولی برنامه هرگز Pillow را نصب نمی‌کند.

## خروجی‌ها
همه خروجی‌ها در `code\outputs` نوشته می‌شوند. پیش‌نمایش‌های GUI نیز در `code\outputs\gui_preview` قرار می‌گیرند.
