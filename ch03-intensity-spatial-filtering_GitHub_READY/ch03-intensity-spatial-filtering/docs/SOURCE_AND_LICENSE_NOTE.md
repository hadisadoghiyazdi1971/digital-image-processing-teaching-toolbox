# Source and redistribution note

This chapter toolbox is an independent educational implementation aligned with the concepts of Chapter 3, *Intensity Transformations and Spatial Filtering*, from Gonzalez & Woods, *Digital Image Processing*, 4th ed.

The public repository intentionally does **not** include scanned textbook pages, textbook figures, or a full reproduced/translated chapter. The code, synthetic examples, and original explanatory notes are distributed separately from the copyrighted book.

For bundled sample-image status, see `../samples/SAMPLE_LICENSES.md`. For upstream scientific libraries, see `GITHUB_REFERENCES.md`.
